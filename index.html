The project

Teaching AI to grow better cells

This summer at NutriGene AI in Hong Kong, we built an AI system to find better recipes for turning stem cells into blood vessel cells, a key step toward new cell therapies.

The wall

300 files, nothing usable

The lab's history arrived as about 300 files: flow cytometry exports, microscope photos, plate reads and protocols, with three experiments mixed together. We found 31 data points. Not one was ready for the AI.

The insight

The AI wasn't the hard part

Understanding what the lab had already done was. Small biotech teams without a data team hit this wall every day, and general AI tools can't read their biology files.

How it works

Obtimize runs every file a lab produces through four steps. Each step exists because skipping it is how labs end up repeating runs or optimizing on bad data.

01

Ingest

Reads everything the lab already produces, read-only, with originals checksummed.

  • Run sheets
  • FCS files
  • Microscope photos
  • Plate reads
  • Protocol changes
  • Calculation sheets
  • Notebooks
  • Slack threads
02

Understand

Rebuilds each experiment as linked facts in the lab's knowledge graph.

  • Conditions
  • Cell line
  • Passage
  • Reagent lot
  • Protocol version
  • Operator
  • Outcome
03

Diagnose

Finds gaps and contradictions before anyone trusts the data.

  • Missing outcomes
  • Unlabeled images
  • Assay version mismatch
  • Batch effects
  • Calculation errors
  • Repeated runs
04

Recommend

Turns verified records into the next round, or says what to fix first.

  • Next experiments
  • Robust operating range
  • Replicates needed
  • Cited answers

Why it's built this way

Files, not forms

Scientists won't re-type their work into new software. So Obtimize reads the run sheets, photos and exports they already save.

A graph, not a folder

A result only means something next to its lot, passage and protocol version. So every fact is stored as a link, not a file.

Diagnose before optimizing

An optimizer fed bad data gives confident wrong answers. So Obtimize fixes gaps first, and holds back when the data can't support a decision.

Faster, cheaper process development

Every differentiation run costs weeks and thousands of dollars in media, cells and scientist time. Obtimize gets labs to a reliable answer with fewer of them.
